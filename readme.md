# Stellar Wallet Assets & Dividenden Visualizer

Streamlit-App, die die Assets einer Stellar-Wallet tabellarisch und grafisch darstellt.
Main-Assets können markiert und andere Trustlines als "Dividenden" zugewiesen werden.
Für jede Dividende wird der letzte eingehende Payment angezeigt.

## Features
- Laden einer öffentlichen G-Adresse
- Übersicht aller Balances / Trustlines
- Main-Asset ↔ Dividenden-Zuordnung
- Letzter Eingang pro Dividende
- Diagramme: Pie, Bar, Treemap, Netzwerk-Graph, Sunburst
- Einstellbares Farbschema + Config-Export/Import
